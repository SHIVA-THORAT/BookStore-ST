# Book Store MERN Application

A full-stack Book Store application built using the MERN stack.

## Tech Stack
- Frontend: React, Tailwind CSS, DaisyUI
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)
- Tools: Vite, Nodemon

## Features
- User authentication
- Browse books
- Add / update books
- RESTful APIs
- Responsive UI

# BookStore-ST
Full-stack Book Store application built using the MERN stack with RESTful APIs, user authentication, and MongoDB integration via environment variables.
